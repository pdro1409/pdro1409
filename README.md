## 🧑‍💻 Sobre Mim

Sou **Desenvolvedor Full Stack Pleno** e estudante de Engenharia de Software, com foco na construção de **sistemas escaláveis, confiáveis e de fácil manutenção**.

Minha principal stack é baseada em **TypeScript, Node.js, Express, React e Next.js**, com forte interesse em engenharia de backend, arquitetura de sistemas e sistemas distribuídos.

Gosto de trabalhar em todo o ciclo de vida do software — desde a **modelagem de bancos de dados e o design de sistemas até APIs, infraestrutura, implantação e monitoramento em produção**.


## 🏗️ Arquitetura de Sistemas

Tenho grande interesse em projetar sistemas que permaneçam **fáceis de manter e confiáveis à medida que crescem**.

```text
                   ┌──────────────────────┐
                   │       CLIENTES       │
                   │ Web / Mobile / API   │
                   └──────────┬───────────┘
                              │
                              ▼
                   ┌──────────────────────┐
                   │    API / GATEWAY     │
                   │ Autenticação · Limite│

                              │
                ┌─────────────┴─────────────┐
```
